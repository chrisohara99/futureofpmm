## Quick Setup

1. Upload `SAP-Future-of-PMM-Training-V3.zip` to SuccessFactors Learning
2. Select **SCORM 1.2** as content type
3. System auto-creates 8 learning items from manifest
4. Restrict visibility to SAP internal only
5. Add attribution to course description (see below)
