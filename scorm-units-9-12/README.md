# Future of PMM Training — Units 9-12

## SCORM 1.2 Package for SAP SuccessFactors Learning

This package contains Units 9-12 of the Future of Product Marketing curriculum, designed to complement the SAP Learning Team's Units 1-8.

## Contents

| Unit | Title | Focus |
|------|-------|-------|
| 9 | Persona Development with AI | Data-driven buyer personas, living persona systems |
| 10 | AI-Powered Launch Excellence | GTM execution, launch tiering, workflow acceleration |
| 11 | The PMM AI Tech Stack | Tool selection, build vs. buy, prompting mastery |
| 12 | Building Your AI-PMM Operating System | Capstone — integrating everything into daily practice |

## How These Units Complement Units 1-8

SAP Learning Team's Units 1-8 cover:
- Evolution of PMM (strategic context)
- Visibility/GEO
- Market Intelligence & Competitive Strategy
- Winning Satisfiers (Analysts)
- Sales Enablement
- Content & Narrative
- Demo Stack
- Pricing & Packaging

Units 9-12 fill the remaining gaps:
- **Persona Development** — foundational but not covered in 1-8
- **Launch Excellence** — GTM execution (they have pieces but not the playbook)
- **Tech Stack** — practical tool guidance to operationalize all the concepts
- **Capstone** — integration of everything into a personal operating system

## Installation in SuccessFactors

1. Upload this ZIP as a SCORM 1.2 package
2. Set completion tracking to "Learner marks complete"
3. Ensure Units 1-8 are prerequisites (recommended)
4. Test in a sandbox environment before production

## Technical Details

- **SCORM Version:** 1.2
- **SCO Count:** 4 (one per unit)
- **Completion Method:** Button click (calls LMSSetValue for lesson_status)
- **Dependencies:** None (standalone HTML/CSS/JS)
